Buying a new computer in 2026 involves more than choosing a processor, graphics card and storage capacity. RAM is another important consideration, and getting the right amount can make the difference between a machine that handles your workload comfortably and one that struggles when several applications are open.

The problem is that memory recommendations can be confusing. Some inexpensive computers still come with 8GB, while gaming machines and professional workstations may offer 32GB, 64GB or considerably more. Paying for memory you never use is wasteful, but buying too little can limit your computer's usefulness over time.

For most people buying a new Windows laptop or desktop, **16GB is a sensible starting point, while 32GB is worth considering for gaming, programming and heavier multitasking**. However, your ideal configuration depends on what you do, which applications you run and whether you can upgrade the memory later.

## What does RAM actually do?

RAM stands for random access memory. It provides temporary working space for the operating system, applications and data your computer needs to access quickly.

Think of it as your computer's workspace. Storage holds your files and applications, while RAM helps keep the information required for current tasks readily available.

When memory becomes insufficient, the operating system can move some data between RAM and storage. This process helps the computer continue operating, but it can introduce delays because storage is generally slower than RAM.

More memory allows a computer to handle more demanding applications and simultaneous tasks without running out of working space. However, additional RAM does not automatically make every application faster. Processor performance, storage speed, graphics hardware and software optimisation remain important.

## How much RAM do you need?

The following recommendations are practical starting points rather than universal minimum requirements.

| RAM capacity | Best suited to | Main limitation |
|---|---|---|
| 8GB | Basic browsing, documents and light everyday tasks | Less comfortable with heavy multitasking |
| 16GB | Students, office work, general productivity and moderate gaming | Can become restrictive for demanding professional workloads |
| 32GB | Serious gaming, programming, creative applications and heavier multitasking | May be unnecessary for basic everyday use |
| 64GB | Large creative projects, virtual machines and demanding technical workloads | Higher cost and limited benefit for ordinary users |
| 128GB or more | Specialist workstations, large datasets and memory-intensive professional tasks | Only justified by specific workload requirements |

These categories overlap. A well-optimised computer with 16GB may outperform a slower system with 32GB in tasks that do not need the additional capacity.

## Is 8GB of RAM enough in 2026?

For basic tasks, 8GB can still be usable. You may be perfectly comfortable writing documents, checking email, streaming video and browsing a modest number of websites.

However, modern browsing habits can consume substantial memory. Keeping numerous tabs open while running video calls, messaging applications and productivity software can leave relatively little available for other tasks.

Windows 11 officially lists 4GB as its minimum memory requirement, but that is a technical installation requirement rather than a recommendation for a comfortable experience. Meeting the minimum does not guarantee smooth performance across demanding applications.

There is another consideration: upgradeability. Many thin laptops use soldered memory that cannot be expanded after purchase. An 8GB configuration could therefore become a long-term limitation even if it meets your current needs.

**Our recommendation:** Choose 8GB only for a genuinely basic workload, a particularly affordable device or a computer that can be upgraded easily. For a new computer intended to last several years, 16GB is generally the safer choice.

## Is 16GB of RAM the sweet spot?

For everyday computing, 16GB offers a useful balance between capacity and cost.

It is a good fit for:

- University assignments, research and office applications.
- Browsing with multiple tabs and running several applications simultaneously.
- Video calls, streaming and general productivity.
- Light photo editing and occasional creative work.
- Casual gaming and many mainstream PC games, subject to their individual requirements.

It is also a reasonable choice for people learning to code. Web development, small Python projects and ordinary programming tasks generally do not require enormous amounts of memory.

The main caveat is that workloads vary. Running several development environments, local databases, virtual machines or memory-intensive applications together can increase demand considerably.

If you are buying a computer for general use and do not have a specific reason to need more, 16GB is a sensible default.

## Should gamers choose 16GB or 32GB?

Gaming is one area where the right answer depends heavily on the games you play and what else runs alongside them.

Many games can run with 16GB, making it a reasonable baseline for a budget-conscious gaming PC. However, demanding titles, extensive modifications and multitasking can make additional capacity useful.

Consider 32GB if you regularly:

- Play demanding modern games while running other applications.
- Stream gameplay or record footage while playing.
- Use large game modifications or complex simulation software.
- Keep browsers, voice-chat applications and launchers open during gaming sessions.

It is important to distinguish system RAM from graphics memory. A graphics card has its own dedicated VRAM, which serves a different purpose. Adding system RAM does not directly increase dedicated VRAM, and neither component can compensate fully for an inadequate graphics card.

Before upgrading, check the requirements of the specific games you play and monitor actual memory usage. If your current system is not running out of RAM, the upgrade may provide less benefit than improving another component.

## How much RAM do programmers and creators need?

For programming, photo editing, video production and other creative work, memory requirements depend on project complexity.

### Programming and software development

16GB is suitable for many beginners and intermediate developers working on websites, scripts and ordinary applications.

32GB becomes more attractive when running multiple development tools, containers, virtual machines, local services or larger projects simultaneously. Specialist workloads can require substantially more.

### Photo and video editing

16GB can be sufficient for lighter projects, but 32GB offers more headroom for demanding editing sessions and larger files.

Professional video workflows, complex effects, high-resolution footage and extensive multitasking can push memory requirements higher. The editing software's recommendations should guide your decision.

### Artificial intelligence and local models

Running AI models locally introduces additional considerations. Requirements depend on the model, its size, quantisation, software framework and whether processing takes place on the CPU or GPU.

System RAM and graphics memory are not interchangeable. A machine with 64GB of system RAM may still struggle to run a model that exceeds its available GPU memory, while some CPU-based workloads can benefit from additional system memory.

For AI work, check the requirements of the particular model and software rather than assuming that more RAM alone guarantees better performance.

## Does 64GB of RAM make sense?

For most everyday users, 64GB is unnecessary. Browsing, studying, office work and ordinary gaming rarely justify that capacity on their own.

It can make sense for professionals working with large datasets, extensive virtualisation, demanding creative projects or specialised applications that genuinely consume substantial memory.

The key question is whether your workload benefits from the additional capacity. If your applications use only a fraction of 32GB, moving to 64GB may make little practical difference.

The same principle applies to 128GB and beyond. These configurations are valuable for particular workstation workloads, not automatically better for everyone.

## Laptop RAM vs desktop RAM

The amount of memory is only part of the decision. How it is installed matters, too.

Desktop computers often allow memory upgrades, although compatibility depends on the motherboard, processor and existing configuration. Some laptops also support upgrades, while others have memory soldered directly to the board.

Apple silicon Macs use unified memory shared by the CPU and GPU. This is not directly equivalent to a conventional desktop configuration with separate system RAM and dedicated graphics memory, so comparisons should consider the entire system.

Before buying, check:

- Whether the memory can be upgraded.
- The maximum supported capacity.
- Whether existing memory occupies available slots.
- Whether the computer uses conventional RAM or unified memory.
- The manufacturer's recommendations for your intended applications.

If you cannot upgrade later, it may be worth buying more memory upfront. However, avoid paying a substantial premium for capacity that your workload is unlikely to use.

## The bottom line

For most people buying a computer in 2026, **16GB of RAM is the best general-purpose starting point**. It provides enough flexibility for everyday computing, studying, multitasking and a wide range of applications.

Choose 8GB only if your needs are modest and the limitations are acceptable. Consider 32GB if you game seriously, develop software with multiple tools or regularly work with demanding creative applications. Reserve 64GB or more for workloads that can genuinely benefit from it.

Above all, treat RAM as one part of a balanced computer. A capable processor, suitable graphics hardware, fast storage and a well-designed system all contribute to performance.

The best configuration is not the one with the largest number on the specification sheet. It is the one that gives you enough capacity for your actual workload without spending money on resources you will never use.
